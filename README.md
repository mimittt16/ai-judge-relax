A short text written to relax the AI judge, for the make.fun ai-judge-relax-01 bounty.

`main.ts` (Node 22, standard library only) writes one fixed text — a night train's dining car after the last stop, 412 characters — to `/output/entry.txt`. It is deterministic: no randomness, no clock, no network, and two runs write identical bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
